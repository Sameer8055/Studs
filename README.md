# Studs

A dedicated, dark-first Android PDF reader focused on fast opening, smooth navigation, and a calm reading experience.

## Product direction

- Read-only PDF experience
- Dark mode by default
- Smooth page navigation and pinch-to-zoom
- Page preview and page jumping
- Remember the last reading position
- Minimal floating bottom controls: previous page, next page, and page preview

## Android app

The app will be built with Kotlin and Jetpack Compose. The repository is currently being scaffolded; build and device testing will be documented as they are completed.
